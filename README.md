# hrv-camera — пульс и метод Баевского по камере телефона

Веб-приложение для Android (Chrome): палец на задней камере со вспышкой, 5 минут записи,
по найденным ударам — индекс напряжения Баевского и показатели вариабельности.
Все данные остаются в телефоне. Не медицинский прибор.

Карточка проекта: `project-hub-vault/06_PROJECTS/trex-hrv.md` (проект начинался с часов T-Rex 3).

## Сейчас

- `probe/` — страница-проверка на 1 минуту: включается ли вспышка, сколько кадров в секунду,
  видна ли пульсовая волна.
- `lib/signal.js` — поиск ударов: точка самого крутого подъёма пульсовой волны с уточнением
  между кадрами. Проверка на искусственной волне: `npm test`.
